









The OpenGL ABI on Windows is frozen to OpenGL 1.1 (and to 1.2 on Linux).
So, opengl32.dll has the implementations of functions only up to OpenGL 1.1.
The implementations of functions that belong to versions beyond 1.1 are provided by the graphics driver 
which is provided by graphics card vendor so the function addresses may vary from system to system. 
So, in order to access these functions opengl32.dll provides wglGetProcAddress function which can be used to obtain a function's pointer at runtime.
We need to use this for each function that we want to use. Also, we need to add checks to make sure that the function exists and that we have received a valid function pointer.
All this is boilerplate code and a loader library like GLAD helps us avoid writing it.

ICD which is part of the graphics drivers, provides a lookup table for the function pointers and this is what is used by the wglGetProcAddress function to get the pointers.
